The Spoken Tutorial Project teaches a Free and Open Source Software (FOSS) tool — such as Linux, Scilab, LaTeX, PHP & MySQL, Java, C/C++, LibreOffice and others — through short instructional videos, followed by an online certification test. This dashboard consolidates every such course conducted at VAST, across five exam cycles and seven departments, so you can see at a glance which FOSS tools have been taught to which batch.
